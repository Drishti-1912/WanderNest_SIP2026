
# 🏡 WanderNest

> AI-powered travel assistant and itinerary planner that helps rural homestays deliver personalized guest experiences through NLP-driven conversation and smart recommendations.

---

## 🛠️ Tech Stack

- **Frontend** — React.js
- **Backend** — Python (FastAPI)
- **AI / NLP** — HuggingFace Transformers / OpenAI API
- **Database** — PostgreSQL
- **Version Control** — Git / GitHub

---

# WanderNest Backend

## Install

```bash
npm install
```

## Start Backend

```bash
npm run dev
```

Runs at

http://localhost:5000

Available APIs

GET /api/homestays

GET /api/homestays/:id

POST /api/homestays

PUT /api/homestays/:id

DELETE /api/homestays/:id

GET /api/homestays/search?location=Kasol
